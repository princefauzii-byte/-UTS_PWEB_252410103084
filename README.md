## Deskripsi
PRODUCTLY merupakan website sederhana untuk pengelolaan data produk dan rating produk. Website ini dibuat sebagai project Ujian Tengah Semester (UTS) mata kuliah Pemrograman Web.

Project ini menggunakan framework Laravel dengan konsep MVC dan Blade Templating. Data produk disimpan dalam bentuk array statis dan ditampilkan melalui halaman website tanpa menggunakan database maupun fitur CRUD.

## Fitur Website
- **Login:** Memasukkan username untuk masuk ke website.
- **Dashboard:** Menampilkan ringkasan informasi produk.
- **Profile:** Menampilkan informasi pengguna.
- **Pengelolaan Produk:** Menampilkan daftar produk, kategori, harga, stok, rating, dan status ketersediaan.

## Teknologi
- PHP
- Laravel
- Blade Templating
- HTML
- CSS
- Bootstrap Icons
